# Static files

Served as-is at the site root.

## Still placeholders

`favicon.svg`, `favicon.ico`, `apple-touch-icon.png`, `icon-192.png`,
`icon-512.png` and `og-default.png` are the starter's artwork and still say
"Origin". They are replaced once the wordmark is in, since all of them are
built from it.

`cv.pdf` is a generated stand-in so the download link works during review. It
says so on its only page. Replacing it means updating the stated size in
`src/config/site.ts` to match — a size the reader is told before they click is
worse than none if it is wrong.
