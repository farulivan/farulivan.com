## The studio is fictional. The build is not.

Norven is an architecture studio that does not exist. The point was never the
firm — it was having a real site, with real content and real constraints, that
I could hold to production standards without a client's deadline deciding what
got cut first.

## What gets enforced

One command, `pnpm verify`, runs format, lint, typecheck, unit tests, build and
a bundle budget. On top of that, every pull request runs:

- **Playwright end-to-end tests with axe**, gating on WCAG AA. Not a report
  somebody reads later — a gate that fails the PR.
- **Lighthouse CI budgets, per page.** Performance, accessibility, SEO and best
  practices each have a floor.
- **CodeQL and dependency review.**

The interesting thing about putting the accessibility check in the gate rather
than the backlog is that it changes what you build. You cannot ship the
component and fix the contrast later, so you pick the accessible version first
and never pay the difference.

## Motion behind one callback

The site is photography-led with scroll-driven motion — GSAP and ScrollTrigger
underneath, but every effect goes through a single `scrollEffect` runtime
rather than each component reaching for the library.

One place to reason about what runs on scroll, one place to respect reduced
motion, and a pure core that unit tests without a browser.

## Deployment without credentials

Static output to S3, behind a single Cloudflare edge, with an IP-allowlisted
origin. Deploys run from GitHub Actions over OIDC, so there are no long-lived
AWS keys anywhere — not in the repo, not in the CI settings, nowhere to leak.

Response headers — CSP, HSTS, Permissions-Policy — are committed as Cloudflare
Transform Rules rather than configured by hand in a dashboard nobody can diff.

A $5/month AWS budget sits over it as a ceiling. Steady state is about two
cents.

## Why this one exists

The decisions are written down as ADRs, alongside a deployment runbook with the
cost analysis and a roadmap with explicit non-goals. If you are skimming the
repo to work out how I build, five minutes should be enough.
