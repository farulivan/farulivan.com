## The problem

Four teams, four button components, and a design review that spent most of its
time on differences nobody had chosen. The previous attempt at a shared library
had been announced rather than adopted, and it sat at one consumer.

## What I built

The second attempt started from the code the teams already had rather than from
a blank file. Each component shipped with a codemod that rewrote the old usage,
so trying it cost a command rather than an afternoon.

Tokens are CSS custom properties rather than a JavaScript theme object, which
means a product can override one value without importing the library into its
build twice.
